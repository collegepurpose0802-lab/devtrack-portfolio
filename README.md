# DevTrack Portfolio

Personal developer portfolio for **Vedansh Saini**, built with plain HTML, CSS and JavaScript.

## Features
- Responsive design
- Dark/light mode
- About, skills, projects and contact sections
- GitHub Pages ready
- No Node.js required

## Files
- `index.html` — page structure and content
- `style.css` — design and responsive layout
- `script.js` — theme toggle

## Deploy
Upload the files to a public GitHub repository and enable GitHub Pages from **Settings → Pages**.

## Customize
Edit your name, bio, projects, skills, GitHub, LinkedIn and email directly in `index.html`.
